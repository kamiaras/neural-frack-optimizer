# Data policy

This tree contains source code and synthetic examples. It contains no original project dataset, trained project model, fitted project scaler, result table, saved notebook output or project run configuration.

The example inputs are generated independently from a seeded random generator and an explicit toy formula in `examples/synthetic_demo.py`. They are not transformed or anonymized project rows. Metrics from that example describe the toy workflow only.

The original project files are retained separately in private storage. They are not part of this public version. Users must supply data and trained artifacts they are allowed to use. Generated local files belong under `artifacts/` and are ignored by Git.

The Python libraries listed in the dependency files retain their own licenses. This repository does not vendor those libraries and adds no new code license.
